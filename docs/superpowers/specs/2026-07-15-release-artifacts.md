# Release artifacts: precompression + nginx config (2026-07-15)

Approved design. Scope: `swiftwui build -c release` (and `ssg` refresh) emits
precompressed `.gz`/`.br` siblings for dist files and a ready-to-deploy
`dist/nginx.conf`; loud hint when `wasm-opt` is missing.

## Motivation (measured, Examples/Counter)

| Artifact | Size |
|---|---|
| release wasm, no wasm-opt (today) | 22.4 MB |
| release wasm + wasm-opt -Os (plugin default when installed) | 8.8 MB |
| + gzip -9 (over the wire) | 3.1 MB |
| + brotli -q 11 (over the wire) | 2.27 MB |

PackageToJS already runs wasm-opt in release when the binary exists; when it
doesn't it prints one buried warning and ships the 22 MB file. The CLI must
surface that loudly.

## New module: `Sources/SwiftWUIToolchain/ReleaseArtifacts.swift`

```swift
public enum ReleaseArtifacts {
    /// Extensions worth precompressing (allowlist; already-compressed
    /// formats — png/webp/woff2/zip/… — are excluded by omission).
    static let compressibleExtensions: Set<String> =
        ["wasm", "js", "mjs", "css", "html", "json", "svg", "txt", "xml", "map", "ts", "webmanifest"]
    static let minSize = 1024  // below this, compression headers outweigh savings

    public struct Summary {
        public var gzipped: Int
        public var brotlied: Int
        public var brotliAvailable: Bool
    }

    /// A `.gz`/`.br` file is FRAMEWORK-OWNED iff its base name's extension is
    /// in `compressibleExtensions`. `index.html.gz` → ours; a user asset
    /// `foo.tar.gz` copied from public/ → never touched (tar ∉ set).
    static func isOwnedCompressed(relPath: String) -> Bool

    /// 1. Remove framework-owned .gz/.br whose base file no longer exists.
    /// 2. For every eligible file (ext ∈ set, size ≥ minSize, not itself
    ///    .gz/.br, not nginx.conf, not a dotfile): regenerate `.gz` (always)
    ///    and `.br` (when brotli is installed) — unconditional regeneration,
    ///    no mtime comparison (stale-sibling bugs beat a few wasted seconds).
    /// gzip: `gzip -kfn9 <file>` (-n → deterministic output, no timestamp).
    /// brotli: `brotli -f -q 11 <file>`.
    /// gzip missing (exotic): print warning, skip — never fail the build.
    /// brotli missing: print one hint (`brew install brotli`), Summary reflects it.
    @discardableResult
    public static func compress(distDir: String, runner: ProcessRunner) throws -> Summary

    /// Remove ALL framework-owned .gz/.br (debug builds call this so a stale
    /// release-compressed sibling never shadows a fresh debug file).
    public static func clean(distDir: String) throws

    /// True when dist contains any framework-owned .gz/.br — `ssg` uses this
    /// to decide whether to refresh compression after rewriting index.html files.
    public static func hasCompressedArtifacts(distDir: String) -> Bool

    /// Overwrite dist/nginx.conf (dist is build output; not user-owned).
    public static func writeNginxConf(distDir: String) throws

    /// `which <tool>` via runner; used for wasm-opt/brotli/gzip probes.
    static func toolAvailable(_ tool: String, runner: ProcessRunner) -> Bool
}
```

## nginx.conf (exact content, string literal in code — no resource plumbing)

```nginx
# Generated by `swiftwui build -c release` — regenerated on every release build.
# Deploy: copy dist/ to the server, set `root` below, then place this file at
# /etc/nginx/conf.d/<app>.conf (or include it from your nginx.conf http block).
server {
    listen 80;
    listen [::]:80;
    server_name _;

    root /var/www/app;  # <-- set to the deployed dist/ path
    index index.html;

    gzip_static on;      # serve the .gz artifacts emitted by the release build
    #brotli_static on;   # serve the .br artifacts — requires the ngx_brotli module

    gzip on;             # runtime fallback for responses without a precompressed sibling
    gzip_types application/wasm application/javascript text/css application/json image/svg+xml;
    gzip_min_length 1024;

    # Bundle file names are not content-hashed -> always revalidate (ETag/304).
    # Deploying under versioned paths? Switch to "public, max-age=31536000, immutable".
    add_header Cache-Control "no-cache";

    location = /nginx.conf { return 404; }  # this file ships inside dist/

    # WebAssembly MIME type — instantiateStreaming requires it; distro
    # mime.types before nginx 1.21.4 lack the entry.
    location ~ \.wasm$ {
        types {}
        default_type application/wasm;
    }

    # SPA fallback; `swiftwui ssg` per-route prerenders are served via $uri/.
    location / { try_files $uri $uri/ /index.html; }
}
```

Rationale: server-block snippet (conf.d style), not a standalone conf —
that's the deploy artifact people actually drop on a server. Wasm MIME via a
regex location with `types {} + default_type`, NOT a server-level
`include mime.types; types {…}` pair: the pair emits a duplicate-extension
warning on nginx ≥ 1.21.4 (mime.types already maps wasm) and hard-fails
(`[emerg]`) when no mime.types sits beside the including conf prefix —
both verified against nginx 1.31.2. The regex location works on old and new
nginx, inherits server-level gzip_static/add_header, and a bare server-level
`types {}` pitfall (replacing the whole inherited map) never arises.

## Wiring

- `BuildCommand.run` (order matters):
  1. Before the wasm build, when `config == "release"` and
     `!toolAvailable("wasm-opt")`: print a prominent multi-line warning —
     release wasm ships ~2.5× larger without it; hint `brew install binaryen`
     (macOS) / distro package (Linux). Never fail.
  2. After `DistLayout.assemble` + PWA manifest: release → `compress` +
     `writeNginxConf` + one summary print; non-release → `clean` (drop stale
     release siblings).
- `SSGCommand.run`: after `copyPublic` + manifest, if
  `hasCompressedArtifacts` → `compress` again (ssg rewrites index.html files;
  a stale index.html.gz beside a fresh index.html means nginx serves old
  markup — the exact gzip_static failure mode).
- `DistLayout.reservedNames` += `"nginx.conf"` (public/nginx.conf would be
  silently clobbered otherwise; loud collision error instead).
- `PWAAssets.isExcluded` += framework-owned `.gz`/`.br` (rule above) and
  `nginx.conf` — build(release) → ssg would otherwise precache multi-MB
  compressed siblings and the config into the service worker.

## Tests (`Tests/SwiftWUITests/ToolchainReleaseTests.swift`)

Follow ToolchainBuildTests patterns (temp dirs, MockRunner where commands are
asserted, real FoundationProcessRunner for the gzip integration path — gzip
exists everywhere; guard the real-brotli assertion on `which brotli`).

1. compress: eligible file ≥ 1 KB gets `.gz`; < 1 KB skipped; `.png` skipped.
2. compress removes framework-owned orphan (`gone.css.gz` without `gone.css`);
   never touches `foo.tar.gz` (orphan or not).
3. MockRunner: exact gzip/brotli argument construction (`-kfn9`, `-f -q 11`).
4. brotli unavailable → Summary.brotliAvailable == false, no `.br` emitted,
   build not failed.
5. clean removes owned `.gz`/`.br`, keeps `foo.tar.gz`.
6. writeNginxConf: file exists, contains `gzip_static on`, `try_files`,
   `application/wasm`; second call overwrites.
7. reservedNames contains `nginx.conf`; copyPublic collision error fires.
8. PWA manifest excludes `app/x.wasm.gz`, `x.br`, `nginx.conf`; still
   includes `foo.tar.gz`.
9. hasCompressedArtifacts true/false.

## Out of scope

- Embedded Swift wasm SDK (`swift-6.3.3-RELEASE_wasm-embedded` is installed
  but unusable: StateStore grafts @State via `Mirror` — embedded Swift has no
  reflection; CLAUDE.md already forbids dropping reflection metadata).
- Bundling/driving wasm-opt ourselves — PackageToJS already does it; we only
  surface the missing-binary case.
- Content-hashed file names / immutable caching (future toolchain work).
